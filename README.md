# Fuel Planning Reference

คู่มือทบทวน **Fuel Planning** สำหรับ Flight Dispatcher — รองรับการเปิดบนมือถือ แท็บเล็ต และคอมพิวเตอร์ และติดตั้งเป็นแอพ (PWA) ได้

## หัวข้อ
- Contingency Fuel (R/R 5% & 3%)
- Re-clearance / Re-dispatch (POR)
- ETOPS / EDTO & Critical Fuel
- Planning without / with multiple Alternate, Isolated Aerodrome
- Worked Examples + In-flight Fuel Management

## การติดตั้งเป็นแอพ
เปิดเว็บไซต์บนมือถือ/แท็บเล็ตแล้วเลือก "เพิ่มลงในหน้าจอหลัก / Install"

> เพื่อการทบทวนและฝึกอบรมเท่านั้น — การปฏิบัติการจริงให้ยึด controlled OM ฉบับล่าสุด
